# Docs Runtime Ops

## Goal
Ensure the project is easy to run, debug, and operate.

## Documentation Outputs
- Local setup and required environment variables
- Start/stop commands (local and Docker)
- Common failures and quick fixes
- Health checks and verification steps

## Workflow
1. Verify commands from a clean environment.
2. Document only commands that are known to work.
3. Add troubleshooting for top recurring errors.
4. Keep docs short and update with each operational change.
