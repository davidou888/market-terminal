# Architecture Decision Record

## Goal
Make technical decisions explicit and revisitable.

## ADR Template
- Context
- Decision
- Alternatives considered
- Trade-offs
- Consequences
- Rollback strategy

## Workflow
1. Define the decision and constraints.
2. List viable alternatives.
3. Compare by correctness, complexity, cost, and risk.
4. Select option and justify with project context.
5. Record expected impact and follow-up tasks.
